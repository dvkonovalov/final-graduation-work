# final-graduation-work

Данный проект представляет собой готовую платформу для предсказания курсов криптовалют (Bitcoin, Etherium, Litecoin).
Сервер построен на **Python Flask** и содержит в себе основные элементы мониторинга и хранения ресурсов.

---

## Предварительные действия

Перед запуском необходимо сгенерировать приватные и публичные ключи для каждого из сервисов. 
Публичный ключи **{service_name}**.pem необходимо добавить в папку **api_gateway/public_serts**.
Приватные ключи private_key.pem необходимо разместить в корне каждого сервиса.

Важным дейстивем является запонение параметров окружения в файле **.env**

## Запуск

```bash
docker compose up --build
```

## Запуск сервера

После запуска платформы ее фронтальная компонента будет доступна по адресу:
```plaintext
http://localhost:5000
```

Кроме того, будут доступны сервис просмотра метрик Grafana по адресу:
```plaintext
http://localhost:3000
```
